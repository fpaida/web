# CMPS262 Grocery Web Frontend

## Description

This project is the frontend web application for the Grocery API developed for CMPS262 at Point Park University.

The application connects to a RESTful API and allows users to view, add, search, and modify grocery products.

## Features

- View grocery products
- Search and sort products
- Paginate product results
- Add new grocery products
- Modify existing grocery products
- Connect to a REST API hosted on Render
- Display API data using Grid.js

## Technologies

- HTML
- CSS
- JavaScript
- Grid.js
- REST API
- Node.js / Express backend
- PostgreSQL
- Render
- Git and GitHub

## API

The frontend communicates with the Grocery API using:

`GET /api/v1/products`

`POST /api/v1/products`

`PUT /api/v1/products/:id`
